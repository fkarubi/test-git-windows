# JANスキャナー（iPhoneアプリ）

iPhoneのカメラでJANコード（EAN-13 / EAN-8）を読み取り、数字をCSVファイルに保存するアプリです。

## 機能
- カメラで連続スキャン（読み取ると「ピッ」という音と振動でお知らせ）
- チェックデジットで誤読を防止
- 同じコードの重複登録を防止（メニューから「重複を許可」に切り替え可能）
- 読み取るたびに CSV を自動保存
- 「CSV共有」ボタンから AirDrop・メール・ファイル保存などで書き出し
- 行を左にスワイプして削除、メニューから全件削除
- **写真で確認**タブ：写真を撮るかライブラリから選び、Macの中継サーバーに送ってバーコードの有無と位置を表示

## 写真で確認モード
1. 画面下の「写真で確認」タブを開き、右上の ⚙ から設定する
   - 中継URL（初期値 `http://100.127.247.83:8787`）
   - 合言葉（iPhoneのキーチェーンにだけ保存。保存後は表示されません）
   - 「接続テスト」で `GET /health` に接続できるか確認できます
2. 「写真を撮る」または「ライブラリ」で写真を選ぶと、`POST /barcode` に送信します
3. 結果
   - 確率が 0.5 以上：「コードあり（確率○%）」と表示し、写真の上に赤い枠を描きます
   - 0.5 未満：「コードなし」と表示します（枠は描きません）
   - しきい値は `JanScanner/RelayConfig.swift` の `barcodeThreshold` の1か所で変えられます

送る前に写真の向きを正立に直してから JPEG にし、画面にも同じ画像を表示するので、サーバーが返す枠の位置と表示がずれません。
TypeSafe の API キーはアプリには入っていません（Macの中継サーバーだけが持っています）。

### 通信設定（ATS）
http の通信は `project.yml` の `NSExceptionDomains` で `100.127.247.83` と `ts.net`（サブドメイン含む）だけに許可しています。
`NSAllowsArbitraryLoads` は使っていません。中継サーバーのIPが変わったら `project.yml` を書き換えて `xcodegen generate` し直してください。

## CSV形式
保存先: 「ファイル」アプリ → このiPhone内 → JANスキャナー → `jan_codes.csv`

```
No,JANコード,読取日時
1,4901085089026,2026/10/09 10:15:30
```
UTF-8（BOM付き）で保存するため、Excelで開いても文字化けしません。

## ビルド方法（Mac が必要）
1. Xcode 15 以降と [XcodeGen](https://github.com/yonaskolb/XcodeGen) をインストール
   ```
   brew install xcodegen
   ```
2. このフォルダでプロジェクトを生成して開く
   ```
   cd JanScanner
   xcodegen generate
   open JanScanner.xcodeproj
   ```
3. Xcode で「Signing & Capabilities」の Team に自分の Apple ID を設定
   （必要なら Bundle Identifier を `com.自分の名前.JanScanner` などに変更）
4. iPhone を USB で接続して ▶ で実行
   - 初回は iPhone の「設定 → 一般 → VPNとデバイス管理」で開発元を信頼してください
   - シミュレーターにはカメラがないため、実機で実行してください

対応OS: iOS 16 以降

テストは Xcode で ⌘U（実際の通信や写真は使いません）。

## iPhoneでの確認手順（写真で確認モード）
事前に Mac で中継サーバーを起動し、⚙ の設定で正しい合言葉を保存して「接続テスト」が「接続できました」になることを確認します。
テストに使う写真は、自分で用意した私物（本・お菓子の箱など）のバーコードにしてください。店の商品・お客様・人を写さないこと。

| # | やること | 期待する表示 |
|---|---|---|
| 1 | バーコードが写った写真を撮る | 「コードあり（確率○%）」＋バーコードの位置に赤枠 |
| 2 | バーコードのない写真（壁・机など）を撮る | 「コードなし」、枠なし |
| 3 | iPhoneのTailscaleをオフにして写真を送る（または接続テスト） | 「つながりません。iPhoneのTailscaleがオンか確認してください」 |
| 4 | ⚙ で違う合言葉を保存して写真を送る | 「合言葉が違います」 |

確認が終わったら、Tailscaleをオンに戻し、正しい合言葉を保存し直してください。
